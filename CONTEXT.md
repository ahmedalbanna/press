# CONTEXT.md — AlbannaTech Press Platform

## Domain Glossary

### Company
- **AlbannaTech**: A technology and software company providing managed cloud hosting, ERPNext/Frappe customization, data seeding, AI agents, and flexible deployment options.
- **Tagline**: "هندسة الأنظمة الذكية لإدارة أعمالك بكفاءة متكاملة"

### Platform
- **Press**: The Frappe Press platform, forked and rebranded for AlbannaTech's hosting business.
- **Dashboard**: The primary customer-facing interface where users manage their sites, invoices, and servers.
- **Marketplace**: The app discovery surface where customers browse and install applications.
- **SaaS Signup/Login**: The first touchpoint for new customers creating accounts.

### Brand Identity
- **Primary Color**: `#0F172A` (deep navy) — headers, primary text, dark backgrounds
- **Secondary Color**: `#0EA5E9` (cyan/sky blue) — accents, links, highlights
- **Accent Color**: `#10B981` (emerald green) — success states, active status
- **Light Background**: `#F8FAFC` — light mode base
- **Dark Background**: `#020617` — dark mode base
- **Arabic Font**: Cairo or Tajawal
- **English Font**: Inter or Plus Jakarta Sans

### Business Model
- **Paid Cloud Hosting**: Customers pay for managed cloud hosting of their ERP systems
- **Free On-Premise**: Customers can install locally for free with annual AI agent subscription
- **AI Agents**: Annual subscription for AI assistants powered by erpnext-mcp
- **Data Seeding**: Pre-configured data structures using frappe-mcp

### Infrastructure
- **Bench**: A running instance of the platform on a server
- **Site**: A Frappe site belonging to a Team, living on a Bench
- **Server**: Physical or virtual machine running the platform
- **Cluster**: A cloud region containing servers

### Key Concepts
- **White-labeling**: Rebranding the platform to present AlbannaTech's identity instead of Frappe Cloud
- **Bilingual**: Full Arabic and English support with RTL/LTR layout
- **RTL**: Right-to-left text direction for Arabic
- **LTR**: Left-to-right text direction for English
